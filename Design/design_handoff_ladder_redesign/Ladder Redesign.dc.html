1 · The architecture

1a

Revised information architecture

— surfaces, what lives where, first-run vs return

LAYER 0

Crisis layer. When triggered, the fixed-copy banner leads whatever surface is open — above the header, never folded, never below other content. It is fed only by the one crisis-gated composer; no surface ever adds a second free-text field.

Home

the front door

  • What changed since last visit
  • What is due: the one ask (check-in, then queued follow-up)
  • First Steps clock — honest range when only the year is known
  • “Add a note” → the standing composer
  • First run: this surface is the interview

Programs

places that can help

  • Matched cards — call / start action on the face
  • State chips: Suggested · Planned · Saved · Enrolled (undo)
  • Things to try at home (guides)
  • Saved for later
  • Catalog-only names, numbers, URLs

Notes

your words, kept

  • Journal by month, “you wrote” quotes
  • Add a note → same composer
  • Visit packet: pickable questions, print / copy
  • “Not a medical record” · stays on this phone

Visit

appointment companion

  • Waitlist → book → reminders → missed → rebook
  • Slot offers with “None of these work” that keeps your place
  • Timeline: now / next / later
  • Tab appears only when a referral fits the child's profile

One composer, crisis-gated

Every “add a note / tell us more” on any surface routes here. It never disappears — on return it collapses to a one-tap “Add a note” row.

Verified catalog

Program names, phone numbers, and URLs come only from it. The app never diagnoses and never says what a family qualifies for.

On-device store

No accounts. Language choice, notes, steps, and packet picks persist on the phone; EN | Español sits in every header.

First run — one intense session

1  Arrival framing (kept verbatim): “Tell us what you have noticed… We do not diagnose.” + example placeholder + yes/no-questions alternative

2  Type or speak → “Sounds like…” strip with you wrote quotes + “Check or change this” (kept)

3  First answer: 3 cards, call on the face, one follow-up question → 1e

4  “You're set” — Home seeds: clock, planned steps, packet started. Tabs appear only now, so the first session stays a single thread.

Return — short monthly visits

1  Home opens on what changed + what is due, never on interview framing → 1b

2  Monthly check-in, ~30 seconds, one question at a time → 1f

3  Queued next ask (step follow-up) only after the check-in closes

4  “Add a note” is one tap into the standing composer — the box never vanishes on return (P3)

why tabs

For GED-level readers at 11pm, four always-visible labeled destinations beat both memory (hub back-stack) and scroll-hunting (one page). The bar is sticky, not fixed, lays out with a wrapping grid, and keeps ≥44px targets — at 200% zoom it wraps 2×2 instead of clipping (the current fixed two-link bar is the thing that breaks, P2/P8 in the audit's zoom test). Trade-offs of the two alternatives are annotated under 1c and 1d.

What First Steps visits look like

Kentucky's early intervention system serves children from birth to age 3 where they spend their day, with the parent in the visit.

  • Expect visits where your child already spends time — home, childcare, the playground — not a clinic room.
  • Plan to take part: visits actively involve the parent instead of treating the child alone.
  • Help name the goals — families set the outcomes on the Individualized Family Service Plan.

Source: Kentucky CHFS, Kentucky Early Intervention System (First Steps) · Checked on 2026-07-25

First Steps stops taking new referrals 45 days before a child turns three. Call your local First Steps office to see if there is still time, and ask what comes next if there is not.
