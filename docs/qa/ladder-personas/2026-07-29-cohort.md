# Ladder persona stress-test cohort and scoring contract

All family details in this cohort are fictional. This is an unconditional non-crisis, non-regression QA run: no case may introduce crisis or regression disclosures. Every case must record a crisis-banner count of `0`, empty `safetyEvents`, and no regression flags.

## Common run contract

Each run must record:

1. isolated starting storage;
2. exact profile and opening;
3. caregiver-attributed facts and source snippets;
4. follow-up relevance and repetition;
5. `latestInterviewDomains` and `activeDomains`;
6. visible resource IDs and order;
7. age/county exclusions;
8. resource action and persisted state;
9. `safetyEvents`, regression flags, and crisis-banner count;
10. screenshots and storage evidence;
11. scores and band;
12. confirmed versus non-reproducing findings.

Run every first-session case in a fresh browser context with empty site storage. Run each longitudinal family in its own separate browser context and retain only that family's state for its continuation and reload checks; no family state may appear in another family's context.

The authoritative execution is the deterministic no-key path at local `http://127.0.0.1:3000/ladder`. The live navigator gate and external AI providers are prohibited for this QA run. F02 and L03 are production smoke repeats only, run after their authoritative local journeys at `https://patient-centered.vercel.app/ladder`; production behavior does not replace or redefine the local result.

Use existing demo controls only. The 31-day control cannot prove an exact 7-day threshold, and no available control can simulate crossing the First Steps birthday cutoff. L04 therefore covers countdown persistence and enrollment retirement only, not birthday-cutoff behavior.

Caregiver education and reading need are interaction and explanation variables only; they are never treated as proxies for intelligence or commitment.

Score each applicable dimension using `2 = expected without material friction`, `1 = usable but degraded`, and `0 = wrong, blocked, lost, or materially unusable`. Score D1–D8 for first-session cases and D1–D10 for longitudinal cases. Score bands are Green `85–100%`, Amber `65–84%`, and Red below `65%`.

| Dimension | Measure |
| --- | --- |
| D1 | Caregiver input understood |
| D2 | Facts extracted accurately and attributed to the caregiver |
| D3 | Follow-up questions relevant and non-repetitive |
| D4 | Child profile captured without unnecessary re-entry |
| D5 | Need domains identified correctly |
| D6 | Resources appropriate for age, county, and stated needs |
| D7 | Next steps understandable and actionable |
| D8 | Language, tone, trust, and absence of false safety escalation |
| D9 | Saved-state continuity (longitudinal only) |
| D10 | Waitlist and appointment progression (longitudinal only) |

Each family run record must begin with its exact heading, such as `# F01 — Theo` or `# L04 — Ava`, so completion can be checked mechanically. The cards below are indexed with level-two headings for the run validator.

## F01 — Theo

- Profile: Pike; May 2024; not school age; no diagnoses.
- Caregiver lens: grandmother guardian; GED; low digital confidence; rural setting.
- Opening: “Theo is two. He says mama and no, but not much else, and he still falls a lot when he walks. His doctor said speech and physical therapy could help. I’m his grandmother and I don’t drive, so we need a ride to appointments. I need somebody to tell me who to call first.”
- Input: voice-style transcript using the existing speech shim when available; otherwise enter the exact transcript as text and label the limitation.
- Coverage boundary: transcript-path coverage only; this is not microphone or acoustic-recognition coverage.
- Expected domains: early intervention, therapies, transportation.
- Prohibited: school/IEP, waivers, diagnosis claims, crisis, regression.
- Resource oracle: `first_steps_big_sandy` before `first_steps_statewide`; `help_me_grow_ky` and `kentucky_211` remain reachable.
- Action: plan the Big Sandy First Steps resource.
